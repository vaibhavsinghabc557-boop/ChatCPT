# ⚡ Chat CPT 1.1.0

> **A lightweight, terminal-native AI workspace powered by the Groq API.**

Chat CPT Pro is a highly optimized, command-line AI assistant designed for developers who demand speed, privacy, and efficiency over bloated web GUIs. It features dynamic persona switching, local file analysis, and secure API key management.

## 🛠️ Core Features
* **Ultra-Fast Inference:** Leverages the Groq API (Llama 3) for near-instant token streaming.
* **Dynamic Persona Engine:** Switch between tailored AI agents on the fly (including a standard assistant, 'Jarvis', and the elite 'Tesseract' coding agent).
* **Local File I/O:** Inject local code files directly into the AI's context for review and analysis using the `/read` command.
* **Terminal-Native UI:** Fully styled with ANSI color formatting for a clean, hacker-friendly CLI experience.
* **Secure Credentialing:** Localized `api_key.txt` storage prevents accidental credential leaks to public repositories.
